# lean-tactics-learning

这是一个专注于解析 **Lean 4 Tactics 行为机制** 的个人化教学仓库。

##  为什么建立这个仓库？

目前 Lean 4 的学习资料往往存在两极分化：
- **过于底层**：直接切入依值类型论与内核语法，学习曲线陡峭；
- **过于黑盒**：仅展示具体 tactic 的调用，缺少对状态转换（State Transition）与边界行为的解释。

本仓库旨在搭建一座桥梁，通过具体、可复现的微型示例，解析常用 tactics 在后台的实际行为与工作逻辑。

##  关于生成机制与严谨性说明

- **多智能体协同生成**：本仓库的大部分笔记由 Multi-Agent 系统协同构建，具体生成机制与 Prompt 工作流请参考 [mul_agents_workflow.md](mul_agents_workflow.md)。
- **形式化检验保障**：仓库内所有笔记涉及的 Lean 代码与形式化结论，**均通过了 Lean 4 编译器/内核的严格类型检查与自动化复现验证**。
- **审阅局限与免责**：虽然形式化代码具有机器保障，但智能体生成的**自然语言解释与行为分析**可能仍存在偏差或幻觉。由于维护者精力与水平有限，无法对所有文字阐述进行逐一精细审查。

##  环境要求

- **Lean 版本**：`leanprover/lean4:v4.33.0`
- 建议配合 VS Code 及 Lean 4 官方插件运行。

##  欢迎反馈与纠错

本仓库拒绝任何学术门槛与权威壁垒：这里没有愚蠢的问题，也不排斥任何尖锐的批评，**无论你是零基础新手还是资深学者，都欢迎随时在此发表你的任何见解**。
